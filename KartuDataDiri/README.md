# DataDiri.js — Instruksi

File ini berisi contoh deklarasi variabel sesuai tugas.

Cara menjalankan:

1. Buka Terminal (PowerShell atau CMD).
2. Jalankan perintah berikut di folder proyek:

```powershell
node "c:\day 1\khusus tugas\KartuDataDiri\DataDiri.js"
```

Silakan ambil screenshot output konsol dan tambahkan file screenshot ke repositori (mis. `screenshot-console.png`).

Saya sudah menyertakan `screenshot-console.txt` yang berisi output konsol saat menjalankan skrip; Anda bisa mengganti dengan `screenshot-console.png` jika ingin meng-upload screenshot sebenarnya.
